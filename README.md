### 一个简单的判断方法

假设某个产品当前结算前显示 100 元，优惠码单独生效后应该变成约 90 元。

但年付特价产品本身就是一个独立的促销价格。比如当前公开页面里，美国 9929 双 ISP 住宅 IP VPS 的年付特价版是 **499 元/年**，而不是拿月付 68 元或 88 元直接乘 12。

所以看优惠时，建议把“产品原价”“当前页面特价”“优惠码之后的结算价”分开看。否则很容易把不同页面的折扣重复计算。
